DeynDhowr — Cusboonaysiin (logada meheradda + ereyada la saxay)
================================================================

1) CMD:
   cd %USERPROFILE%\Downloads
   tar -xf deyndhowr-update.zip
   (Waxay beddelaysaa: index.html, admin.html, SETUP.txt, supabase\schema.sql.
    config.js-kaaga LAMA TAABANAYO.)

2) Supabase → SQL Editor → New query:
   cd deyndhowr-app
   notepad supabase\schema.sql
   Ctrl+A, Ctrl+C → Supabase-ka ku dheji → Run
   (Waa ammaan in mar kale la shubo. Xogtaada waa la ilaalinayaa.)

3) GitHub:
   git add . && git commit -m "Logada meheradda + ereyada" && git push

4) App-ka: Ctrl+Shift+R → Habaynta → Dukaanka → "Soo geli logo".
